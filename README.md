# Category Launcher (Visual Category Navigation)

Concept for review for the Harvey Norman homepage category row. Not the live site, and not signed off.

- `index.html`: the concepts on a capture of the live homepage, with the CMS-ready code (`cms/`) and its images (`cms/images/`)
- `tile-ideas/`: image ideas for the Beds & Manchester and Carpet, Flooring & Rugs tiles
- `history.html`: earlier Harvey Norman homepage category navs, from the Internet Archive

Built from the handoff kit (`vcn-handoff/vcn/build5.py`, then `site.py`).
